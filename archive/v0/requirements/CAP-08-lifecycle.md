# CAP-08: API Lifecycle Management — Requirements

**Priority:** Should Have | **Phase:** MVP

---

## Requirements

| ID | Requirement | User |
|---|---|---|
| REQ-CAP08-01 | APIs shall have lifecycle states: Draft, In Review, Live, Deprecated, Retired | System |
| REQ-CAP08-02 | A producer shall be able to update the lifecycle state of their API | Producer |
| REQ-CAP08-03 | A deprecated API shall display a deprecation banner on its detail page | System |
| REQ-CAP08-04 | The catalogue shall support filtering by lifecycle state | Consumer |
| REQ-CAP08-05 | Consumers subscribed to a deprecated API shall receive advance notification | System |
| REQ-CAP08-06 | A retired API shall be removed from the active catalogue | System |

---

## Prototype status

Not built. All 6 requirements are achievable without a backend.
