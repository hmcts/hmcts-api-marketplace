# CAP-14: Platform Administration — Requirements

**Priority:** Must Have | **Phase:** MVP

---

## Requirements

| ID | Requirement | User |
|---|---|---|
| REQ-CAP14-01 | An administrator shall be able to manage users, roles and organisations | Administrator |
| REQ-CAP14-02 | An administrator shall be able to configure approval workflows and SLA thresholds | Administrator |
| REQ-CAP14-03 | An administrator shall be able to manage the API taxonomy, domains and classification standards | Administrator |
| REQ-CAP14-04 | The system shall provide platform health monitoring and incident management | System |
| REQ-CAP14-05 | An administrator shall be able to publish platform-wide announcements (deferred) | Administrator |
| REQ-CAP14-06 | Platform usage reporting shall be available to administrators (deferred to Phase 2) | Administrator |

---

## Prototype status

Not built. The reviewer role partially covers administrative functions. A dedicated admin role and dashboard are not yet implemented.
