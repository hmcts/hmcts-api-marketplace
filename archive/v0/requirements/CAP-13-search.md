# CAP-13: Search & Data Discovery Intelligence — Requirements

**Priority:** Should Have | **Phase:** Phase 2

---

## Requirements

| ID | Requirement | User |
|---|---|---|
| REQ-CAP13-01 | The search shall support full-text matching across endpoint descriptions and schema field names | Consumer |
| REQ-CAP13-02 | The system shall support business-language search mapping | Consumer |
| REQ-CAP13-03 | The system shall display related API suggestions based on domain and search context | Consumer |
| REQ-CAP13-04 | The system shall provide "did you mean" suggestions for near-match searches | Consumer |
| REQ-CAP13-05 | The catalogue shall surface recently added and trending APIs | Consumer |

REQ-CAP13-03 (related APIs in sidebar) is outstanding but achievable without a backend. Remainder deferred to Phase 2.
